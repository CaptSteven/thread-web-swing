# 双人联网对战

这是两人局域网原型，没有账号、匹配服务器或公网中继。

1. 两台电脑安装 Godot 4.7.2，并使用同一份 `web-swing-demo` 项目。Mac 上可以直接复制整个 game 文件夹，然后双击 `Play Demo.command`；其他系统用 Godot 导入 `project.godot`，按 F6 运行。
2. 两台电脑连接同一 Wi-Fi 或局域网。
3. 房主点击“创建房间”，将界面显示的局域网 IP 发给另一人。有多个地址时选择当前 Wi-Fi 的地址。
4. 另一人输入房主 IP，点击“加入房间”。加入成功后双方进入对战。
5. 若系统询问 Godot 的本地网络访问／入站连接权限，需要允许。房间使用 UDP 24816。访客 Wi-Fi 的设备隔离可能阻止互连。

左键按住使用蛛丝，右键按住连发射击，鼠标瞄准。每人 100 血，每发 20 伤害；两秒后自动复活，复活有一秒保护。掉出地图也会复活，不为对方计分。对手为橙色，自己为白色；顶部显示血量和比分。没有胜利局数限制，可持续练习。

Esc 打开房间菜单，可离开或切回单人练习。正常战斗只用两个鼠标键。房主离开时房间关闭，客户端返回练习；不支持房主迁移。

房主计算角色物理、子弹碰撞、生命和计分，客户端发送瞄准与按键输入，30Hz 接收状态。此版未加入客户端预测、插值或延迟补偿，优先用于低延迟局域网；公网需要可达的房主地址及 UDP 24816 端口转发，运营商 NAT 可能使它不可用。

验证：本机两个独立 Godot 进程通过 ENet 实测连接、客户端蛛丝输入、子弹击杀、血量与计分同步、复活、离开清理、重新加入。实际两台电脑的 Wi-Fi／防火墙环境仍需现场验证。
