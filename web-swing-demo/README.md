# Thread — 蛛丝摆荡 Demo

现已支持双人局域网对战：启动后选择创建／加入房间。完整连接步骤和限制见 [LAN-PLAY.md](LAN-PLAY.md)。双方各 100 血、每发 20 伤害、2 秒复活、1 秒复活保护，房主统一计算物理与命中。

双键玩法：左键按住使用蛛丝，右键按住朝鼠标方向连发射击（约每秒 7 发）。射击不改变已连接的蛛丝落点，没有后坐力、换弹或弹药限制。通道内有六个橙色靶子，每个三发击毁，五秒后恢复；子弹会被平台和障碍阻挡。HUD 显示累计击毁数。R 是测试重置快捷键，正常游玩不需要键盘。

受力修订：短丝的径向阻尼降低，弹性系数按发射时长度固定，避免靠近粘着点时突然变硬。受力超限需累计持续 0.16 秒才断，低于阈值会恢复；单帧尖峰不会立即断裂。自动松丝需越过粘着点平面 12 像素且实际开始远离粘着点，仍在靠近时不会误松丝。以下旧版规则中的“立即断裂”和单纯越过竖直线已由此规则替代。

使用 Godot 4.7.2 打开 `project.godot`，按 F6 或 F5 运行。

- 按住鼠标左键：沿指针方向发射蛛丝，附着到射线击中的第一座建筑；最大距离 820 像素。
- 附着后继续按住左键：蛛丝逐渐绷紧，通过弹性张力牵引角色；保留横向惯性，依靠重力形成弧线摆荡。短丝更紧、长丝更柔和。
- 松开左键：断开蛛丝，保留速度，随后受重力和建筑碰撞影响。
- 角色只能靠蛛丝移动；A/D、方向键、空格和 W/S 不再控制角色。
- R：回到起点；坠落后自动重置。

瞄准时不显示落点、虚线、范围或自定义准星，仅保留系统鼠标指针。地图为上下交错的平台，中间仅有三个小障碍；镜头保持上下平台可见。起点瞄准右上方平台下缘，按住左键即可逐渐被拉离起点。交替连接上方和下方平台，借惯性穿过中间通道。

蛛丝按弹性伸长和径向拉扯速度计算张力，超过 2900 游戏力单位立即断裂；检测在加速度限幅之前进行。受力接近极限时已发射的蛛丝变红。受力、过长或障碍造成的断裂会产生两段松散蛛丝，弯曲下坠并在 1.2 秒内淡出。掉落动画仅作用于断丝，人物姿态和惯性不变。

蛛丝最多持续 2.4 秒，最后半秒淡出。角色沿发射时的水平朝向越过粘着点的竖直线时会自动断丝；近乎垂直的发射按上下越过判定。断丝保留速度，松开再按左键连接下一点，不会在持续按住时自动重新附着。

长度超过 580 像素会累积损伤，越长断裂越快；达到 1050 像素立即断裂。蛛丝会随损伤变红，界面显示长度和损伤。断裂不清除速度，松开再点击可发射新蛛丝。角色不受键盘方向控制。

这是纯代码绘制的单关卡原型，没有外部美术依赖。建筑有碰撞；蛛丝被其他楼体挡住时会断开，暂不支持绕楼角。
